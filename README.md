# NEXUS DOC AI
## Constraint-Aware Error Detection for Document Extraction
### Premium Cinematic Black & Red Web Application

A state-of-the-art intelligent document verification system designed to eradicate accounting ledger corruption by validating extracted invoice data across **three dimensions**:

1. **Perception Checking** — Optical readability, image contrast, scan blur, and character ambiguity detection ('8' vs 'B', '0' vs 'O').
2. **Layout-Based Checking** — Spatial geometry, label-to-value bounding box proximity, and table column baseline alignment.
3. **Constraint-Based Validation** — 100% deterministic mathematical verification (`Subtotal + Tax == Total`, Line item accumulation, and chronological date logic).

---

## 🌟 Architecture & Features

### 1. Three-Dimensional Defense Matrix
- **Perception Checking**: Flags blurred or low-confidence text and highlights optical confusion risks (e.g., character 'B' mistaken for numeral '8' in financial totals).
- **Layout Checking**: Analyzes coordinate geometry to prevent catastrophic field misidentifications (e.g. identifying a tax amount or shipping fee as the invoice total).
- **Constraint Validation**: Enforces hard accounting laws:
  - `Subtotal + Tax == Total Amount` with exact variance delta calculation.
  - `Quantity × Unit Price == Line Total`.
  - `Sum(Line Totals) == Subtotal`.
  - `Due Date >= Invoice Issuance Date`.
  - Cross-Model agreement checks.

### 2. Multi-Factor Risk Assessment
- Derives a weighted harmonic reliability index (50% Constraints, 25% Perception, 25% Layout).
- Categorizes documents into **CRITICAL**, **HIGH**, **MEDIUM**, and **LOW** risk queues for optimal human reviewer triage.

### 3. Human-in-the-Loop Verification
- Interactive field correction suite with real-time arithmetic feedback.
- Instant re-evaluation of mathematical constraints upon correction.
- Persistent audit logging in SQLite with reviewer signatures and timestamped notes.

### 4. Audit Dossier & PDF Generation
- Generates official, downloadable audit reports powered by ReportLab with full verification matrices and mathematical proofs.

### 5. Signature Visual Feature
- An animated cinematic document intelligence visualizer demonstrating invoices moving through **PERCEPTION → LAYOUT → VALIDATION** with pulsing nodes, radar sweeps, and scanning laser traces.

## 🛠️ Running the Application

### 1. Start the Backend API (FastAPI)
```bash
cd nexus-doc-ai/backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```
API endpoints will be live at `http://127.0.0.1:8000/api/` (Swagger docs at `/docs`).

### 2. Start the Frontend (Vite React)
```bash
cd nexus-doc-ai/frontend
npm run dev
```
The web application will be live at `http://localhost:5173`.
